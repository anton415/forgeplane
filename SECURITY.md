# Security Policy

## Supported Versions

Forgeplane is in early development. Security fixes are applied to the latest released version on `main`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Forgeplane, please report it privately. **Do not open a public GitHub issue.**

Send a detailed report to:

- **Email:** anton415@gmail.com
- **Subject:** `[SECURITY] Forgeplane - <short description>`

Please include:

- A description of the vulnerability and the affected component.
- Steps to reproduce, or a proof-of-concept if available.
- The version (or commit hash) where you observed the issue.
- Any suggested mitigation, if known.

## Response Process

You can expect:

- An acknowledgement within **5 business days**.
- An initial assessment and a planned fix timeline within **10 business days**.
- Public disclosure only after a fix is available, coordinated with the reporter.

Thank you for helping keep Forgeplane and its users safe.
